# 🍜 WANGO - Delivery (หว้านโก เดลิเวอรี่)
### แพลตฟอร์มสั่งอาหารและของกินระดับอำเภอหว้านใหญ่ จังหวัดมุกดาหาร (Hyperlocal Food Delivery Web Platform)

---

## 📌 ภาพรวมโครงการ (Project Overview)
**WANGO - Delivery** ถูกออกแบบและพัฒนาขึ้นมาเพื่อเป็นศูนย์กลางการสั่งอาหารออนไลน์ของคนในพื้นที่ **อำเภอหว้านใหญ่ จังหวัดมุกดาหาร** โดยเฉพาะ รวบรวมร้านอาหารท้องถิ่น ร้านสตรีทฟู้ดตลาดแลง ร้านดังริมตลาดเทศบาล ร้านส้มตำรสแซ่บ และคาเฟ่ชุมชน เพื่อให้คนในอำเภอสั่งอาหารได้ง่าย สะดวก และพร้อมเชื่อมต่อระบบการจัดการไรเดอร์และกระจายงานส่งอาหารอัตโนมัติด้วย **Shipday API**

---

## 🌟 ฟังก์ชันหลักของระบบ (Core Features)

### 1. ฝั่งลูกค้า (Customer Experience - UX/UI ทันสมัยแบบมืออาชีพ)
- **ระบบเลือกตำแหน่งจุดส่งในอำเภอหว้านใหญ่**:
  - เลือกแลนด์มาร์คสำคัญ เช่น *ตลาดสดเทศบาลหว้านใหญ่, โรงพยาบาลหว้านใหญ่, โรงเรียนหว้านใหญ่, ที่ว่าการอำเภอ, สี่แยกไฟแดง* หรือพิมพ์ชื่อหมู่บ้าน/ซอยเองได้
- **ระบบค้นหาและกรองร้านอาหาร**:
  - ค้นหาตามชื่อร้าน, เมนู, ประเภทอาหาร (ตามสั่ง, ส้มตำ/ยำ, ก๋วยเตี๋ยว/ต้มเส้น, คาเฟ่/ชา-กาแฟ, สตรีทฟู้ด)
  - กรองร้านส่งฟรี, ร้านส่งไวที่สุด, ร้านเรตติ้ง 4.8+ ดาว
- **หน้ารายละเอียดร้านค้าและเมนูอาหาร (Interactive Menu & Customizer)**:
  - เลือกระดับความเผ็ด (ไม่เผ็ด, เผ็ดน้อย, เผ็ดกลาง, เผ็ดอีสานแท้)
  - เลือกขนาด (ธรรมดา, พิเศษ, จัมโบ้)
  - เลือกท็อปปิ้งเพิ่มเติม (ไข่ดาว, แคบหมู, หมูกรอบ, เพิ่มชีส ฯลฯ)
  - ระบุหมายเหตุถึงทางร้าน (เช่น ไม่ใส่ผักชี, แยกพริกน้ำปลา)
- **ระบบตะกร้าและคำนวณราคาอัตโนมัติ (Cart Management)**:
  - คำนวณค่าอาหาร, ค่าจัดส่งตามระยะทางในพื้นที่อำเภอ
  - รองรับโค้ดส่วนลด (เช่น `WANGOFREE` ส่งฟรี 3 กม. แรก, `WANGO50` ลด 50 บาท, `LOCAL10` ลด 10%)
- **ระบบชำระเงิน (Checkout & Payment)**:
  - สแกนจ่ายผ่าน **พร้อมเพย์ (PromptPay QR Code)** พร้อมแสดงยอดเงินจริง
  - ชำระเงินสดปลายทาง (Cash on Delivery - COD)
  - บัตรเครดิต / เดบิต
- **ระบบติดตามสถานะคำสั่งซื้อแบบเรียลไทม์ (Live Order Tracking)**:
  - แผนที่จำลองเส้นทางไรเดอร์ในอำเภอหว้านใหญ่
  - สเต็ป 5 ขั้นตอน (รับออเดอร์ ➔ กำลังปรุง ➔ ไรเดอร์รับอาหาร ➔ กำลังนำส่ง ➔ ส่งสำเร็จ)
  - แสดงโปรไฟล์ไรเดอร์ ป้ายทะเบียนรถ และปุ่มกดโทรออกหาไรเดอร์

---

### 2. ฝั่งร้านค้า (Merchant Portal)
- สามารถสลับเข้าสู่ **"โหมดร้านค้า"** จากปุ่มด้านบน
- ดูรายการออเดอร์เข้าสดแบบ Real-Time พร้อมปุ่มกดยืนยันรับออเดอร์เข้าครัว และปุ่มเรียกไรเดอร์
- สรุปยอดขายรายวัน จำนวนออเดอร์ และคะแนนรีวิวร้านค้า
- ปุ่มเปิด/ปิดรับออเดอร์ของร้านชั่วคราว

---

### 3. ระบบเชื่อมต่อ Shipday API (Shipday Delivery Dispatch Integration)
- มีโมดูล **Shipday API Integration Center** ในตัว
- รองรับการใส่ **Shipday API Key** เพื่อยิง Order Dispatch เข้าสู่ระบบ Shipday ทันทีที่ลูกค้าสั่งซื้อ
- รองรับ **Sandbox Simulated Mode** สำหรับทดสอบ Flow การจ่ายงานไรเดอร์และแผนที่ Tracking ได้อย่างสมบูรณ์แม้ยังไม่ได้ใส่ Key
- มีโค้ดตัวอย่างการต่อ **Webhook** เพื่อรับ Event เมื่อไรเดอร์รับงาน/ส่งเสร็จ

## 🚀 วิธีการเปิดใช้งานและการนำไปขึ้นระบบ (Deployment Guide)

### วิธีที่ 1: เปิดใช้งานบนเว็บเบราว์เซอร์ทันที (Frontend Standalone)
ไฟล์ `index.html` ถูกออกแบบมาให้ทำงานได้แบบ Single Page Application (SPA) ทันที:
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บน Google Chrome, Safari หรือ Edge
2. สามารถทดสอบสั่งอาหาร, ปรับแต่งเมนู, ใส่โค้ดส่วนลด `WANGOFREE`, สแกนพร้อมเพย์ และติดตามสถานะแบบ Live Tracking ได้ทันที

### วิธีที่ 2: Deploy ขึ้น Hosting ฟรี (Vercel / Netlify / Cloudflare Pages)
- **Cloudflare Pages / Netlify / Vercel**:
  - ลากโฟลเดอร์นี้ไปวางใน Netlify Drop (drop.netlify.com) หรือเชื่อมต่อกับ GitHub Repository เพื่อเปิดใช้งานเป็นเว็บจริงได้ฟรีภายใน 1 นาที

### วิธีที่ 3: รันคู่กับ Node.js / Express Backend (สำหรับ Production)
```bash
# ติดตั้ง dependencies
npm install express cors dotenv axios

# รัน Backend Server
node server_example.js
```

## 🔑 การตั้งค่า Shipday API เมื่อได้รับ API Key

1. นำ API Key ที่ได้จาก Shipday Dashboard (Settings > API Key)
2. คลิกปุ่ม **"Shipday API"** ที่แถบเมนูด้านบนของหน้าเว็บ
3. กรอก API Key แล้วกด **"บันทึก Key"** (ระบบจะจำไว้ใน LocalStorage อัตโนมัติ)
4. หรือหากใช้ Backend Server ให้สร้างไฟล์ `.env` ดังนี้:
   ```env
   PORT=4000
   SHIPDAY_API_KEY=your_actual_shipday_api_key_here
   ```
