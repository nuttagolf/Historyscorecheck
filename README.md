# 🍜 WANGO - Delivery (หว้านโก เดลิเวอรี่)
### แพลตฟอร์มสั่งอาหารและรวมร้านเด็ดระดับอำเภอหว้านใหญ่ จังหวัดมุกดาหาร (Hyperlocal Customer Food Ordering Platform)

---

## 📌 ภาพรวมโครงการ (Project Overview)
**WANGO - Delivery** พัฒนาขึ้นเพื่อเป็นศูนย์รวมร้านอาหาร ของกินท้องถิ่น และสตรีทฟู้ดใน **อำเภอหว้านใหญ่ จังหวัดมุกดาหาร** (ริมแม่น้ำโขง, แก่งกะเบา, วัดสองคอน, ตลาดเทศบาล) ออกแบบให้เป็นเว็บสำหรับ **ผู้สั่งอาหาร (ลูกค้า)** โดยตรง เน้นความสะดวก สั่งง่าย เลือกระดับความเผ็ดและท็อปปิ้งได้จริง บังคับเข้าสู่ระบบด้วย Google เพื่อบันทึกประวัติการสั่งซื้อ พร้อมแสดง QR Code พร้อมเพย์ชำระเงินอัตโนมัติ

---

## 🌟 ฟังก์ชันการทำงานหลัก (Features)

1. **ระบบสั่งอาหารสำหรับลูกค้า (Customer-Centric Interface)**:
   - รวบรวมเมนูอาหารและราคาจากร้านค้าในอำเภอหว้านใหญ่
   - มีข้อความกำกับชี้แจง: *ข้อมูลเมนูและราคาถูกรวบรวมเพื่ออำนวยความสะดวก ราคาหน้าร้านจริงอาจมีการปรับเปลี่ยนตามช่วงเวลา*
   - ปรับแต่งอาหารได้จริง (ขนาดธรรมดา/พิเศษ/จัมโบ้, ระดับความเผ็ด 4 ระดับ, เพิ่มท็อปปิ้ง, ระบุหมายเหตุ)
   - คำนวณราคาแบบเรียลไทม์ตามตัวเลือกที่กดเลือก

2. **ระบบล็อกอิน Google (Mandatory Google Authentication)**:
   - บังคับให้ผู้สั่งอาหารเข้าสู่ระบบด้วยบัญชี Google ก่อนขั้นตอน Checkout เพื่อความปลอดภัยและบันทึกประวัติ
   - แสดงโปรไฟล์ รูปภาพ และชื่อผู้ใช้ Google บนแถบเมนู
   - ดึงข้อมูลชื่อและอีเมลมาใส่ในฟอร์มจัดส่งอัตโนมัติ

3. **ระบบชำระเงินด้วย PromptPay QR Code Generator**:
   - สร้าง QR Code พร้อมเพย์ตามยอดชำระเงินจริงของออเดอร์ (รวมค่าจัดส่งและหักส่วนลดแล้ว)
   - มีทางเลือกชำระเงินสดปลายทาง (Cash on Delivery)

4. **การเชื่อมต่อ Shipday Dispatch แบบเบื้องหลัง (Hidden Background Integration)**:
   - หน้าเว็บไม่มีปุ่มหรือเมนูแสดง API Key ให้รกสายตาลูกค้า
   - การจ่ายงานไรเดอร์ในอำเภอหว้านใหญ่ทำงานผ่าน API เบื้องหลังอย่างปลอดภัย

## 🚀 วิธีการเปิดใช้งาน

### 1. เปิดใช้งานแบบ Standalone บนเบราว์เซอร์
- ดับเบิลคลิกไฟล์  บน Google Chrome, Edge หรือ Safari
- ใช้งานระบบเลือกร้าน, ปรับระดับความเผ็ด, เข้าสู่ระบบ Google, สแกน QR Code พร้อมเพย์ และติดตามสถานะได้ทันที

### 2. นำขึ้น Web Hosting ฟรี (Vercel / Netlify / Cloudflare Pages)
- นำโฟลเดอร์โครงการไปวางที่ Netlify Drop หรือเชื่อมต่อกับ GitHub เพื่อเปิดออนไลน์ให้คนในอำเภอหว้านใหญ่สั่งอาหารได้ 24 ชม.
