# แผนที่เช็กราคาตลาดสดทั่วไทย (Market Price Map)

เว็บแอปพลิเคชัน Single Page Application (SPA) สำหรับเช็กราคาสินค้าเกษตรและอาหารสดจากตลาดทั่วทุกภูมิภาคในประเทศไทย พร้อมระบบอัปเดตราคาแบบอัตโนมัติ

## 📁 โครงสร้างไฟล์
- `index.html` : หน้าเว็บแผนที่แบบ Interactive ออกแบบสำหรับมือถือโดยเฉพาะ
- `scraper.py` : สคริปต์ Python อัปเดตราคาและพิกัดตลาดทั่วไทย
- `prices.json` : ไฟล์ฐานข้อมูลราคาสดที่หน้าเว็บใช้อ่าน
- `.github/workflows/update-price.yml` : คำสั่งรันบอทอัปเดตราคาอัตโนมัติทุกวันบน GitHub Actions

## 🚀 วิธีเปิดใช้งานบน GitHub Pages ฟรี
1. สร้าง New Repository บน GitHub (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดขึ้น Repository
3. ไปที่เมนู **Settings** -> **Pages** -> เลือก Branch **main** แล้วกด Save
4. รอระบบสร้าง URL เว็บพร้อมเปิดใช้งานบนมือถือได้ทันที
